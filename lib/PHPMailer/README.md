# PHPMailer (bundled)

Used by `lib/bosk-mailer.php` to send website enquiry emails from
`info@boskfurniture.com`. Do not edit these files; to upgrade, replace the
three files in `src/` with the same files from a newer PHPMailer 6.x release.
